# Investor showcase MP4 export

The Remotion composition is configured to render to an MP4 file:

```bash
npm run remotion:render
```

Or run the helper script directly:

```bash
./scripts/render-investor-video.sh
```

Default output path:

- `out/investor-showcase.mp4`

Custom output path:

```bash
./scripts/render-investor-video.sh /absolute/or/relative/path/custom-name.mp4
```
